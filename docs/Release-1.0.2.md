# 合盖不休眠 1.0.2

修复关闭“合盖继续运行”后，“合盖时锁定屏幕”也失效的问题。

- 合盖锁屏现在独立生效，可以合盖锁屏，同时允许 Mac 正常休眠。
- 增加系统即将休眠的通知处理，在合盖休眠前请求锁屏，避免只靠定时检查来不及处理。
- 菜单状态包含三个独立开关；“全部关闭”会关闭所有功能。
- 将快捷入口改为“开启亮屏与合盖运行”，保留用户单独选择的合盖锁屏设置。

**升级：** 先在旧版菜单选择“恢复休眠并退出”，再下载 `Mac-Lid-Awake-1.0.2-arm64.dmg`，将新版应用拖入 Applications。

构建、应用签名检查、DMG 校验，以及开关组合和休眠通知处理的模拟检查均已通过。正常合盖休眠时的实际锁屏效果，仍需在设备上确认。

Apple 芯片版本，最低构建目标 macOS 14。尚未取得 Apple Developer ID 签名及 Apple 公证，首次打开可能需要按“隐私与安全性”中的提示处理。合盖继续运行仍需要管理员授权；持续运行请保持通风。

附件提供 DMG 安装包和 `SHA256SUMS.txt` 校验文件。
