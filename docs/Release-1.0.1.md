# 合盖不休眠 1.0.1

现在可以单独选择合盖时是否锁屏。

- 新增“合盖时锁定屏幕”开关，默认关闭，并记住你的选择。
- 关闭后，工具合盖只熄屏，Mac 中的任务继续运行，不主动锁屏。
- 开启后，合盖立即熄屏并锁定。
- 手动锁屏与“锁屏保持亮屏”功能继续可用。

macOS 自身的密码要求仍然生效。系统设置为“永不”且上述开关关闭时，工具不会在合盖时额外锁屏。

**升级：** 先在旧版菜单中选择“恢复休眠并退出”，再安装新版。下载 `Mac-Lid-Awake-1.0.1-arm64.dmg`，将应用拖入 Applications。

Apple 芯片版本，最低构建目标为 macOS 14；已在 M4 Pro、macOS 26.6.2 上确认新版功能可用，其他系统和机型尚未验证。构建、应用签名检查和 DMG 校验已通过。

本版本尚未取得 Apple Developer ID 签名及 Apple 公证。首次打开可能需要按“隐私与安全性”中的提示允许打开，参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

合盖继续运行仍需要管理员授权，并影响整台 Mac 的休眠。持续运行请保持通风；突然断电等情况下，可能需要重新打开应用并恢复设置。

附件包含安装包与 `SHA256SUMS.txt` 校验文件。
