# 合盖不休眠 1.1.0

现在可以分别设置接电源和使用电池时的合盖行为。

- **接电源：** 默认合盖继续运行，并记住开关选择。
- **使用电池：** 默认允许正常休眠，也可以手动开启合盖继续运行。
- 软件运行并完成本次系统授权后，插拔电源会自动切换规则，无需反复输入密码。
- 关闭电池开关不影响接电源运行，合盖锁屏和锁屏亮屏继续独立控制。
- “全部关闭”会关闭所有规则；退出软件恢复原系统设置。独立恢复进程继续处理异常退出。

**升级方法：** 先在旧版菜单中选择“恢复休眠并退出”，再下载 `Mac-Lid-Awake-1.1.0-arm64.dmg`，将新版拖进 Applications。首次打开新版请完成一次系统授权。

软件需要保持运行，不会自动开机启动，也不会唤醒已经休眠的 Mac。接电源规则关闭的选择会被记住，如需恢复默认行为，请重新开启该开关。

构建、应用签名检查和 DMG 校验均已通过。电源切换、开关组合、异常恢复以及管理员权限启动链路的模拟检查通过；真实插拔电源与合盖行为仍需在设备上确认。

当前提供 Apple 芯片版本，最低构建目标 macOS 14。尚未取得 Apple Developer ID 签名及 Apple 公证，首次打开可能需要按“隐私与安全性”中的提示处理。

保持运行时也会影响手动休眠，持续运行请保持通风。突然断电等情况下，下次打开可能需要手动恢复设置。

附件包含 DMG 安装包和 `SHA256SUMS.txt` 校验文件。
