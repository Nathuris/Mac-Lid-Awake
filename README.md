# 合盖不休眠 · Mac Lid Awake

一个 macOS 菜单栏小工具：锁屏后保持亮屏，合盖后立即黑屏，Mac 中的任务继续运行。合盖时是否主动锁屏可单独设置。

## 功能

| 操作 | 显示器 | Mac |
|---|---|---|
| 开盖锁定屏幕 | 锁屏界面持续亮着 | 继续运行 |
| 合上 Mac | 立即黑屏，按开关决定是否主动锁屏 | 按“合盖继续运行”开关决定是否保持运行 |
| 重新打开 Mac | 恢复亮屏；如已锁定，仍需验证身份 | 继续运行 |

锁屏亮屏、合盖继续运行、合盖锁屏三个开关独立控制。菜单显示当前状态，并提供全部关闭和恢复休眠后退出的入口。

“合盖时锁定屏幕”默认关闭，并记住选择。1.0.2 修复了它依赖“合盖继续运行”的问题：关闭继续运行后，仍可合盖锁屏并让 Mac 正常休眠。关闭合盖锁屏后工具不会主动锁屏；macOS 自身的密码要求仍然生效。

## 下载与安装

在 [Releases](https://github.com/Nathuris/Mac-Lid-Awake/releases) 下载 DMG，将应用拖进 Applications 后打开。应用位于屏幕右上角的菜单栏，所有功能默认关闭。

升级前请先通过旧版菜单恢复休眠并退出。

当前提供 Apple 芯片版本，最低构建目标为 macOS 14。实际验证环境为 M4 Pro MacBook Pro、macOS 26.6.2，其他系统与机型尚未验证。

本版本采用本地签名，尚未取得 Apple Developer ID 签名及 Apple 公证。首次打开可能被 macOS 阻止，请在确认下载来源可信后，按“系统设置 → 隐私与安全性”中的提示允许打开。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 休眠与恢复

合盖继续运行需要管理员授权，会修改整台 Mac 的禁止休眠设置，适用于接电源及使用电池的情况，也会影响手动休眠。密码由 macOS 的授权窗口处理，应用不会保存密码。

正常关闭功能或退出会恢复原设置。本次运行期间会启动独立恢复进程，在主程序异常退出后尝试恢复。它不会注册开机服务。

突然断电、主程序与恢复进程同时被强制结束等情况下，不能保证即时恢复。再次打开应用会检查设置，必要时显示恢复入口。

持续运行会耗电并产生热量，请保持通风，不要将仍在运行的 Mac 放进包里。任务能否联网还取决于网络及任务自身。

锁屏使用 macOS 非公开接口，系统更新可能影响兼容性。

## 本地构建

需要 Xcode 及其命令行工具，无第三方依赖。

```sh
zsh Scripts/构建1.0.2.sh
```

脚本生成新的发布目录，包含应用、图标、DMG 和 SHA-256 校验文件，不覆盖已有产物。

恢复链路检查使用模拟设置，不修改真实休眠设置：

```sh
python3 Tests/验证恢复.py
python3 Tests/验证独立锁屏.py
```

## 项目结构

- `Sources/main.swift`：菜单栏与休眠控制。
- `Resources/恢复守护.sh`：本次运行的恢复进程。
- `Scripts/绘制图标.swift`：应用图标的矢量绘制源。
- `Scripts/构建1.0.2.sh`：当前版本的应用与安装包构建。

源码公开供查看。当前未指定开源许可证。
